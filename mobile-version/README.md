# Mobile Version

Godot 4 mobile project driven by OpenSpec.

## Structure

- `openspec/`: specs, proposed changes, and project context.
- `scenes/`: Godot scenes.
- `scripts/`: GDScript source.
- `assets/`: game assets.
- `tests/`: test helpers or future Godot test suites.

## Workflow

1. Create or refine an OpenSpec change under `openspec/changes/`.
2. Implement the change in Godot/GDScript.
3. Validate the change and sync specs when behavior is accepted.
